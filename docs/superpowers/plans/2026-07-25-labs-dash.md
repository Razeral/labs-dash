# labs-dash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy the index page at `labs.ai.tech.gov.sg` — 49 project cards in five fantasy-themed tiers, IP-fenced and TechPass-gated, with owner-only drag-and-drop re-tiering.

**Architecture:** A static Vite/React/TS SPA served from a private S3 bucket through CloudFront with Origin Access Control. Two independent gates: a WAF web ACL (default BLOCK, allow the shared corp IP set) and a labs-auth `cognito-at-edge` Lambda@Edge on viewer-request. Data is a committed `projects.json`; drag-and-drop writes tier overrides to localStorage and exports a replacement file to commit. No backend, no runtime fetch.

**Tech Stack:** Vite 5, React 18, TypeScript 5, Vitest + @testing-library/react, Playwright, AWS CLI (S3, CloudFront, WAFv2, Cognito, Lambda).

**Spec:** `docs/superpowers/specs/2026-07-25-labs-dash-design.md` — read it before Task 1.

## Global Constraints

- TypeScript everywhere. Functional style, no classes. 2-space indent. **No semicolons.**
- Conventional commit messages (`feat:`, `fix:`, `chore:`, `docs:`, `test:`). **No co-author lines.**
- Animation is **CSS only** — no Motion, Framer, GSAP, or animation runtime. Drag uses native HTML5 drag-and-drop plus CSS transitions.
- Every animated effect must be disabled under `@media (prefers-reduced-motion: reduce)`, retaining opacity transitions only.
- AWS region for the pool/bucket: `ap-southeast-1`. WAF and Lambda@Edge and ACM: `us-east-1`. Account: `323001028968`.
- Every AWS resource created gets tags `Project=labs-dash`, `Owner=ng_shangru`, `Environment=prd`.
- Never print AWS credentials, tokens, cookies, or ID-token contents in logs or test output.
- Cognito callback path is **`/_callback`** (underscore). The labs-auth README's `/callback` is wrong.
- **Do not run `provision-federation.sh`** — it rewrites every app client's callback URLs. Enable TechPass on the `dash` client with a targeted `update-user-pool-client` (Task 9).
- `.env.sample` is kept current with every new deploy variable.
- Before any AWS command, load credentials with `eval "$(grep '^export AWS_' ~/.zprofile)"` and confirm with `aws sts get-caller-identity`. If it fails, STOP and ask the user to run `refreshaws` — never loop on failed calls.

- [ ] **Step 3: Write the implementation**

`src/overrides.ts`:

```ts
import { TIERS } from './types'
import type { Project, Tier, TierOverrides } from './types'

export const STORAGE_KEY = 'labs-dash:overrides'

const isTier = (value: unknown): value is Tier =>
  typeof value === 'string' && (TIERS as string[]).includes(value)

export const readOverrides = (): TierOverrides => {
  const raw = localStorage.getItem(STORAGE_KEY)
  if (!raw) return {}
  try {
    const parsed = JSON.parse(raw) as Record<string, unknown>
    return Object.fromEntries(
      Object.entries(parsed).filter(([, tier]) => isTier(tier))
    ) as TierOverrides
  } catch {
    return {}
  }
}

export const writeOverride = (slug: string, tier: Tier): TierOverrides => {
  const next = { ...readOverrides(), [slug]: tier }
  localStorage.setItem(STORAGE_KEY, JSON.stringify(next))
  return next
}

export const clearOverrides = (): void => localStorage.removeItem(STORAGE_KEY)

export const applyOverrides = (projects: Project[], overrides: TierOverrides): Project[] =>
  projects.map((p) => (overrides[p.slug] ? { ...p, tier: overrides[p.slug] } : p))

export const exportRoster = (projects: Project[], overrides: TierOverrides): string =>
  JSON.stringify(applyOverrides(projects, overrides), null, 2) + '\n'
```

## Task 4: Owner identification from the Cognito cookie

**Files:**
- Create: `src/auth.ts`
- Test: `src/auth.test.ts`

**Interfaces:**
- Consumes: nothing
- Produces: `readEmailFromCookie(cookie: string): string | null`, `isEditEnabled(cookie: string, search: string, ownerEmail: string): boolean`

**Context for the implementer:** `cognito-at-edge` stores the ID token in a cookie named `CognitoIdentityServiceProvider.<clientId>.<username>.idToken` without `httpOnly`, so `document.cookie` can read it. The token is a JWT: three base64url segments separated by dots; the middle segment is the JSON payload carrying an `email` claim. **Never log the token or the decoded payload.**

- [ ] **Step 1: Write the failing test**

`src/auth.test.ts`:

```ts
import { describe, it, expect } from 'vitest'
import { readEmailFromCookie, isEditEnabled } from './auth'

const OWNER = 'owner@tech.gov.sg'

const fakeIdToken = (email: string) => {
  const payload = btoa(JSON.stringify({ email })).replace(/=+$/, '')
  return `header.${payload}.signature`
}

const cookieWith = (email: string) =>
  `foo=bar; CognitoIdentityServiceProvider.abc123.someone.idToken=${fakeIdToken(email)}; baz=qux`

describe('readEmailFromCookie', () => {
  it('extracts the email claim from the id token', () => {
    expect(readEmailFromCookie(cookieWith(OWNER))).toBe(OWNER)
  })

  it('returns null when no id token cookie is present', () => {
    expect(readEmailFromCookie('foo=bar')).toBeNull()
  })

  it('returns null on a malformed token', () => {
    expect(readEmailFromCookie('CognitoIdentityServiceProvider.a.b.idToken=garbage')).toBeNull()
  })

  it('returns null on an empty cookie string', () => {
    expect(readEmailFromCookie('')).toBeNull()
  })
```

```ts
const ID_TOKEN_PATTERN = /CognitoIdentityServiceProvider\.[^.]+\.[^.]+\.idToken=([^;]+)/

const decodeSegment = (segment: string): unknown => {
  const padded = segment.replace(/-/g, '+').replace(/_/g, '/')
  return JSON.parse(atob(padded + '='.repeat((4 - (padded.length % 4)) % 4)))
}

export const readEmailFromCookie = (cookie: string): string | null => {
  const match = cookie.match(ID_TOKEN_PATTERN)
  if (!match) return null
  const parts = match[1].split('.')
  if (parts.length !== 3) return null
  try {
    const payload = decodeSegment(parts[1]) as { email?: unknown }
    return typeof payload.email === 'string' ? payload.email : null
  } catch {
    return null
  }
}

export const isEditEnabled = (cookie: string, search: string, ownerEmail: string): boolean => {
  if (!new URLSearchParams(search).has('edit')) return false
  const email = readEmailFromCookie(cookie)
  return Boolean(email) && email!.toLowerCase() === ownerEmail.toLowerCase()
}
```

```tsx
import type { Project } from '../types'

type Props = {
  project: Project
  successorHost?: string
  draggable: boolean
  overridden: boolean
  onDragStart: (slug: string) => void
}

const hostLabel = (host: string) => new URL(host).hostname

export const Card = ({ project, successorHost, draggable, overridden, onDragStart }: Props) => {
  const { slug, name, blurb, tier, host, absorbedInto, note } = project

  const href =
    tier === 'fallen' ? undefined
    : tier === 'ascended' ? successorHost
    : host

  const meta =
    tier === 'ascended' ? `⟶ ascended into ${absorbedInto?.name}`
    : tier === 'fallen' ? '† no longer answers'
    : host ? hostLabel(host)
    : '⌀ UNSUMMONED'

  const className = [
    'card',
    `card--${tier}`,
    href ? 'card--linked' : 'card--inert',
    overridden ? 'card--overridden' : ''
  ].filter(Boolean).join(' ')

  const body = (
    <>
      <span className="card__name">{name}</span>
      <span className="card__blurb">{blurb}</span>
      <span className="card__meta">{meta}</span>
      {note && <span className="card__note">{note}</span>}
    </>
  )

  const shared = {
    className,
    draggable,
    onDragStart: () => onDragStart(slug),
    'data-slug': slug
  }

  return href
    ? <a {...shared} href={href} rel="noreferrer">{body}</a>
    : <div {...shared}>{body}</div>
}
```

```tsx
import { useEffect, useMemo, useRef, useState } from 'react'
import { TierSection } from './components/TierSection'
import { EditBar } from './components/EditBar'
import { readOverrides, writeOverride, clearOverrides, applyOverrides, exportRoster } from './overrides'
import { isEditEnabled } from './auth'
import { TIERS } from './types'
import type { Project, Tier } from './types'
import seed from './data/projects.json'
import './styles/tokens.css'
import './styles/app.css'

const roster = seed as Project[]
const OWNER = import.meta.env.VITE_OWNER_EMAIL ?? ''

export const App = () => {
  const [overrides, setOverrides] = useState(() => readOverrides())
  const dragged = useRef<string | null>(null)

  const editing = useMemo(
    () => isEditEnabled(document.cookie, window.location.search, OWNER),
    []
  )

  const resolved = useMemo(() => applyOverrides(roster, overrides), [overrides])

  const hostBySlug = useMemo(
    () => Object.fromEntries(roster.filter((p) => p.host).map((p) => [p.slug, p.host as string])),
    []
  )

  useEffect(() => {
    const els = document.querySelectorAll('.tier')
    const io = new IntersectionObserver(
      (entries) => entries.forEach((e) => e.isIntersecting && e.target.classList.add('is-revealed')),
      { rootMargin: '0px 0px -10% 0px' }
    )
    els.forEach((el) => io.observe(el))
    return () => io.disconnect()
  }, [])

  const handleDrop = (tier: Tier) => {
    const slug = dragged.current
    dragged.current = null
    if (!slug || !editing) return
    setOverrides(writeOverride(slug, tier))
  }

  const handleCopy = () => {
    navigator.clipboard.writeText(exportRoster(roster, overrides))
  }

  const handleReset = () => {
    clearOverrides()
    setOverrides({})
  }

  return (
    <main className="board">
      <header className="board__header">
        <h1 className="board__title">The Labs</h1>
        <p className="board__sub">A bestiary of {roster.length} works, ranked by vitality.</p>
      </header>

      {editing && (
        <EditBar
          changeCount={Object.keys(overrides).length}
          onCopy={handleCopy}
          onReset={handleReset}
        />
      )}

      {TIERS.map((tier) => (
        <TierSection
          key={tier}
          tier={tier}
          projects={resolved.filter((p) => p.tier === tier)}
          hostBySlug={hostBySlug}
          editing={editing}
          overrides={overrides}
          onDragStart={(slug) => { dragged.current = slug }}
          onDrop={handleDrop}
        />
      ))}
    </main>
  )
}
```

```bash
#!/usr/bin/env bash
# provision-edge.sh — deploy a labs-auth edge gate and repoint a distribution at it.
# Publishing a version does NOT change what CloudFront serves; this does both halves.
set -euo pipefail
cd "$(dirname "$0")"; source lib/aws-env.sh
APP="${1:?app name e.g. dash}"
DIST="${2:?cloudfront distribution id}"
FN="labs-${APP}-edge"
ZIP="edge-auth/${APP}-edge.zip"
[ -f "$ZIP" ] || { echo "ERROR: $ZIP not found — run edge-auth/build.sh ${APP}" >&2; exit 1; }

ROLE_ARN="$(aws iam get-role --role-name CustomIAMREditor --query 'Role.Arn' --output text)"

if aws lambda get-function --function-name "$FN" --region us-east-1 >/dev/null 2>&1; then
  aws lambda update-function-code --function-name "$FN" --region us-east-1 \
    --zip-file "fileb://${ZIP}" >/dev/null
  aws lambda wait function-updated --function-name "$FN" --region us-east-1
else
  aws lambda create-function --function-name "$FN" --region us-east-1 \
    --runtime nodejs20.x --handler index.handler --role "$ROLE_ARN" \
    --zip-file "fileb://${ZIP}" --timeout 5 --memory-size 128 \
    --tags Project=labs-dash,Owner=ng_shangru,Environment=prd >/dev/null
  aws lambda wait function-active --function-name "$FN" --region us-east-1
fi

VER_ARN="$(aws lambda publish-version --function-name "$FN" --region us-east-1 \
  --query 'FunctionArn' --output text)"
echo "published ${VER_ARN}"

# Surgically repoint the distribution, preserving WAF / OAC / cert / IsIPV6Enabled.
tmp="$(mktemp -d)"
aws cloudfront get-distribution-config --id "$DIST" > "$tmp/full.json"
ETAG="$(jq -r '.ETag' "$tmp/full.json")"
jq --arg arn "$VER_ARN" '.DistributionConfig
  | .DefaultCacheBehavior.LambdaFunctionAssociations = {
      Quantity: 1,
      Items: [{ LambdaFunctionARN: $arn, EventType: "viewer-request", IncludeBody: false }]
    }' "$tmp/full.json" > "$tmp/config.json"

aws cloudfront update-distribution --id "$DIST" --if-match "$ETAG" \
  --distribution-config "file://$tmp/config.json" >/dev/null
echo "repointed ${DIST} — waiting for deploy"
aws cloudfront wait distribution-deployed --id "$DIST"
echo "done"
rm -rf "$tmp"
```

`chmod +x provision-edge.sh`.
